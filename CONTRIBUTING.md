# Contributing

Welcome:

- Connection guides for more agents and vendors (`docs/connect/`).
- Receiver examples in other languages or frameworks, with tests.
- Fixes to the library and the protocol text.

Out of scope: how Moyik runs a discussion (scheduling, prompts, moderation, scoring). That is not part of this repository and we can't take changes to it here.

Before opening a pull request, run `npm test` and `npm run typecheck`. Keep the library free of runtime dependencies.
